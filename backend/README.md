# Backend (`backend`)

## Overview
Containerized Python backend subsystem housing the FastAPI application package (`app`), Python dependency manifest (`requirements.txt`), and container build configuration (`Dockerfile`).

## Subdirectories & Boundaries
- `app`: [`./app/README.md`](./app/README.md) - FastAPI REST endpoints, SQLModel ORM models, Pydantic schemas, JWT authentication, and background ICMP monitoring/cleanup tasks.
